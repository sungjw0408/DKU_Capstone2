## 마감 알림 (`expo-notifications`)

- 로그인하면 알림 권한을 묻고, 문서·할 일 목록으로 알림을 예약한다. 로그아웃하면 이 앱이 예약한 알림을 모두 지운다.
- 규칙 (`src/utils/notificationPlan.js`)
  - 계획을 등록한 문서: 마감 D-3, D-1, 당일 알림 시각
  - 할 일: 날짜가 있으면 그날 알림 시각 (같은 날 여러 개면 하나로 묶음)
  - 할 일을 모두 끝낸 문서, 지운 문서, 완료한 할 일, 이미 지난 시각은 제외
  - iOS 보관 한도(64개) 때문에 가까운 순으로 60개까지
- 문서·할 일을 바꾸는 요청(POST/PUT/PATCH/DELETE)이 성공하면 `api.js` → `dataEvents.js` 신호로 목록을 다시 받아 예약을 새로 맞춘다. 그래서 등록·삭제·완료·마감일 변경이 모두 같은 길로 반영된다.
- 알림을 누르면 그 문서의 관리 화면으로 이동한다.
- 웹은 예약 알림을 지원하지 않아 예약하지 않는다(알림함 목록은 보임).
- 개발 중에는 Metro 터미널에 `[마감 알림] N개 예약`과 목록이 찍힌다.

## 설정 탭

- 계정 / 알림 / 앱 정보로 나눴다.
- 계정 칸은 `src/components/settings/AccountSection.js`로 분리해 비워 두었다. 로그인/보안 담당이 채운다.
- 알림: 켜기·끄기, 알림 시각(오전 7·8·9시, 낮 12시, 오후 6·9시). 바꾸면 바로 다시 예약된다.
- 앱 정보: 버전, 앱 소개 다시 보기, 만든 사람.

## 사용성

- 문서가 하나도 없으면 홈과 내 문서에 "첫 공지를 추가해 보세요" + 공지 추가하기 버튼 (`EmptyStart.js`).
- 첫 실행 안내 3장 (`OnboardingModal.js`). 한 번 보면 다시 안 뜨고, 설정 → 앱 소개 다시 보기로 다시 연다.
- 내 문서(할 일 탭 → 문서)에 제목 검색과 상태 필터(전체 / 진행 중 / 마감 지남 / 완료).
  - 완료: 계획 등록 + 할 일 모두 체크 / 마감 지남: 완료 전 + 마감일 지남 / 진행 중: 그 외
